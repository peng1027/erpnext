## 一、系統簡介

### 1.1 功能概述

本系統提供現場稽核人員透過掃描廠商工人的 QR Code，快速執行安全稽核並自動記錄結果。

**核心功能：**
- 📱 掃描工人訪客通行證 QR Code
- 📋 自動載入對應的稽核檢查表
- ✅ 即時計算稽核分數
- ⚠️ 不合格時自動建立 NCR（不符合報告）
- 📊 追蹤工人稽核歷史

### 1.2 稽核判定標準

```
┌─────────────────────────────────────────────────┐
│                  稽核評分機制                    │
├─────────────────────────────────────────────────┤
│                                                 │
│   計分方式：                                     │
│   ─────────                                     │
│   分數 = (通過項目數 ÷ 總項目數) × 100%         │
│                                                 │
│   判定標準：                                     │
│   ─────────                                     │
│   >= 80% ───────> ✓ Pass (合格)                │
│   <  80% ───────> ✗ Fail (不合格) + 自動NCR    │
│                                                 │
│   NCR 嚴重等級：                                 │
│   ─────────────                                 │
│   不合格項目 >= 3 ───> Critical (嚴重)          │
│   不合格項目 <  3 ───> Major (重大)             │
│                                                 │
└─────────────────────────────────────────────────┘
```

## 四、常見問題 (FAQ)

### Q1：掃描 QR Code 失敗怎麼辦？

**可能原因與解決方式：**

| 問題 | 解決方式 |
|------|---------|
| 光線不足 | 移至光線充足處，或開啟手電筒 |
| QR Code 模糊 | 請工人重新列印通行證 |
| 相機權限未開啟 | 檢查瀏覽器相機權限設定 |
| 網路連線問題 | 確認網路連線正常 |

**備選方案：** 可手動輸入通行證號碼（VP-XXXXXXXX-XXXX）

### Q2：通行證顯示「已過期」？

通行證有效期限已過，請聯繫接待處為工人重新核發通行證。

### Q3：稽核不合格但沒有產生 NCR？

NCR 自動產生條件：
- 稽核分數低於 80% **且**
- 至少有 1 項為「不合格」

如果只是「不適用」項目較多，可能不會產生 NCR。

### Q4：如何修改已提交的稽核？

已提交的稽核無法修改，如有錯誤請：
1. 記錄正確資訊
2. 聯繫系統管理員
3. 由管理員在後台更正

### Q5：可以使用哪些設備進行稽核？

支援的設備：
- 智慧型手機（iOS/Android）
- 平板電腦
- 配備攝影機的筆記型電腦

瀏覽器要求：Chrome、Safari、Firefox 最新版本
