## 1. 系統概述

### 1.1 功能特點

| 功能 | 說明 |
|------|------|
| QR Code 掃描 | 掃描廠商工人通行證，自動帶出稽核檢查表 |
| 智能模板選擇 | 根據工人類型自動選擇對應檢查模板 |
| 即時評分 | 自動計算稽核分數，判定合格/不合格 |
| 自動 NCR | 不合格時自動建立不符合報告 (NCR) |
| 歷史追蹤 | 查詢工人過往稽核記錄與統計 |

### 1.2 稽核流程圖

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  掃描 QR    │ --> │  檢視工人   │ --> │  執行稽核   │ --> │  提交結果   │
│  Code       │     │  資訊       │     │  檢查       │     │             │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
                                                                   │
                                                                   v
                                              ┌────────────────────┴────────────────────┐
                                              │                                         │
                                              v                                         v
                                    ┌─────────────────┐                     ┌─────────────────┐
                                    │  分數 >= 80%   │                     │  分數 < 80%     │
                                    │  結果: Pass     │                     │  結果: Fail     │
                                    │  完成稽核       │                     │  自動建立 NCR   │
                                    └─────────────────┘                     └─────────────────┘
```

### 1.3 NCR 嚴重等級

| 不合格項目數 | 嚴重等級 | 處理期限 |
|-------------|---------|---------|
| >= 3 項 | Critical (嚴重) | 7 天 |
| < 3 項 | Major (重大) | 7 天 |

## 2. 稽核人員操作流程

### 2.1 步驟一：掃描工人 QR Code

**操作方式：**
1. 開啟稽核掃描頁面

## 3. API 整合指南

### 3.1 可用 API 端點

| API 端點 | 方法 | 說明 |
|----------|------|------|
| `/scan_worker_qr` | POST | 掃描工人 QR Code，取得資訊與檢查表 |
| `/submit_field_inspection` | POST | 提交稽核結果 |
| `/get_inspection_templates` | GET | 取得可用稽核模板清單 |
| `/get_worker_inspection_history` | GET | 取得工人稽核歷史 |

### 3.2 掃描工人 QR Code

**端點：**
```
POST /api/method/vendor_inspection.vendor_inspection.field_inspection_api.scan_worker_qr
```

**參數：**
| 參數 | 必填 | 說明 |
|------|------|------|
| qr_data | 是 | QR Code 內容 (JSON 字串或通行證號碼) |
| template_name | 否 | 指定使用的檢查模板 |

**範例請求：**
```bash
curl -X POST "https://vendorqc.duckdns.org/api/method/vendor_inspection.vendor_inspection.field_inspection_api.scan_worker_qr" \
  -H "Content-Type: application/json" \
  -d '{
    "qr_data": "{\"type\":\"VISITOR_PASS\",\"pass_number\":\"VP-20251127-0001\"}"
  }'
```

### 3.3 提交稽核結果

**端點：**
```
POST /api/method/vendor_inspection.vendor_inspection.field_inspection_api.submit_field_inspection
```

**參數：**
| 參數 | 必填 | 說明 |
|------|------|------|
| pass_number | 是 | 通行證號碼 |
| findings | 是 | 稽核發現 (JSON 陣列) |
| project_site | 否 | 工地名稱 |
| template_name | 否 | 使用的模板名稱 |
| remarks | 否 | 整體備註 |
| latitude | 否 | GPS 緯度 |
| longitude | 否 | GPS 經度 |

**findings 格式：**
```json
[
    {
        "item_name": "安全帽配戴",
        "result": "Pass",        // Pass, Fail, N/A
        "score_weight": 1,
        "remarks": ""
    }
]
```

**範例請求：**
```bash
curl -X POST "https://vendorqc.duckdns.org/api/method/vendor_inspection.vendor_inspection.field_inspection_api.submit_field_inspection" \
  -H "Content-Type: application/json" \
  -d '{
    "pass_number": "VP-20251127-0001",
    "findings": [
        {"item_name": "安全帽配戴", "result": "Pass", "score_weight": 1},
        {"item_name": "反光背心", "result": "Fail", "score_weight": 1, "remarks": "未穿戴"}
    ],
    "remarks": "需要改善"
  }'
```

**成功回應：**
```json
{
    "message": {
        "success": true,
        "inspection_name": "VI-0042",
        "overall_result": "Fail",
        "score": 50.0,
        "ncr_name": "NCR-0003",
        "message": "稽核完成 - Fail (50.0%)"
    }
}
```

## 5. 常見問題

### Q1: 掃描 QR Code 後顯示「通行證已過期」？
**A:** 工人的訪客通行證已超過有效期限。請聯繫接待處為工人重新核發通行證。

### Q2: 找不到對應的稽核模板？
**A:** 系統會根據工人類型 (visitor_type) 自動選擇模板：
- Contractor → 承包商安全檢查
- Vendor → 供應商稽核檢查
- 其他 → 預設安全檢查

如需使用特定模板，可在 API 呼叫時指定 `template_name` 參數。

### Q3: 稽核不合格時沒有產生 NCR？
**A:** NCR 只在以下條件同時滿足時才會自動建立：
1. 稽核分數低於 80%
2. 至少有一項檢查結果為 Fail

### Q4: 如何修改 NCR 的處理期限？
**A:** 登入系統後，進入 Vendor Inspection > NCR，開啟對應的 NCR 記錄，修改「Due Date」欄位後儲存。

### Q5: 工人沒有訪客通行證怎麼辦？
**A:** 請先至 Visitor Pass 模組為工人建立訪客通行證，產生 QR Code 後即可進行稽核掃描。
