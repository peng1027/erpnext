**必填欄位** (標示 *)：
| 欄位 | 說明 | 範例 |

| Visitor Name | 訪客姓名 | 王小明 |
| Visitor From | 來自公司/單位 | ABC 供應商公司 |
| Valid From | 生效日期 | 2025-11-26 |

## 4. 操作流程三：長期承包商通行證

### 步驟 4.1：建立 30 天長期通行證

與一般通行證建立流程相同，但將 **Validity Days** 設為 **30**：

```
┌─────────────────────────────────────────────────────────────────┐
│  New Visitor Pass - 長期承包商                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Visitor Name:     張工程師                                     │
│  Visitor From:     長期維護承包商公司                           │
│  Purpose:          月度設備維護                                 │
│                                                                 │
│  ┌─── 有效期設定 (重點!) ─────────────────────────────────────┐ │
│  │                                                            │ │
│  │  Valid From:        2025-11-26                             │ │
│  │  Validity Days:     [30] ← 設為 30 天                      │ │
│  │  Valid Until:       2025-12-26 (自動計算)                  │ │
│  │                                                            │ │
│  └────────────────────────────────────────────────────────────┘ │
│                                                                 │
│  💡 30 天內可重複進出，每次進出都會被記錄                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 步驟 4.2：長期通行證的多日使用

```
┌─────────────────────────────────────────────────────────────────┐
│  VP-20251126-0007 - 長期承包商通行證                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Status: 🟢 Active     有效期: 2025-11-26 ~ 2025-12-26         │
│                                                                 │
│  ┌─── 本月進出記錄 ───────────────────────────────────────────┐ │
│  │                                                            │ │
│  │  📅 Day 1 (11/26): 入 09:00 | 出 18:00 | 9.0 hrs          │ │
│  │  📅 Day 2 (11/27): 入 08:30 | 出 17:30 | 9.0 hrs          │ │
│  │  📅 Day 3 (11/28): 入 09:15 | 出 18:30 | 9.25 hrs         │ │
│  │  📅 Day 4 (11/29): 入 08:45 | (在場中)                     │ │
│  │  ...                                                       │ │
│  │                                                            │ │
│  │  📊 本月統計: 訪問 4 次 | 總時數 27.25 小時                │ │
│  │                                                            │ │
│  └────────────────────────────────────────────────────────────┘ │
│                                                                 │
│  ⚠️ 通行證將於 2025-12-26 到期，請提前續期                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 長期通行證 vs 單日通行證比較

| 項目 | 單日通行證 | 長期通行證 (30天) |
|------|-----------|------------------|
| Validity Days | 1 | 30 |
| 進出次數 | 1 次 | 無限次 |
| 離場後狀態 | Used (已使用) | Active (保持有效) |
| 適用對象 | 一般訪客 | 承包商、長期合作夥伴 |
| 記錄保存 | 單筆 | 多筆 (Child Table) |

## 7. 常見問題處理

### Q1: QR Code 掃描失敗怎麼辦？

```
┌─────────────────────────────────────────────────────────────────┐
│  ❌ 掃描失敗處理                                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  可能原因:                                                      │
│                                                                 │
│  1️⃣ 通行證已過期                                                │
│     → 檢查 Valid Until 日期                                     │
│     → 需要建立新的通行證                                        │
│                                                                 │
│  2️⃣ QR Code 模糊或損壞                                          │
│     → 重新下載或列印 QR Code                                    │
│                                                                 │
│  3️⃣ 通行證尚未生效                                              │
│     → 檢查 Valid From 日期                                      │
│     → 等待生效日期或修改設定                                    │
│                                                                 │
│  4️⃣ 網路連線問題                                                │
│     → 檢查掃描器網路連線                                        │
│     → 聯繫 IT 支援                                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Q2: 如何延長通行證有效期？

```
┌─────────────────────────────────────────────────────────────────┐
│  🔄 延長有效期                                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │

│                                                                 │
│  1. 建立新的 Visitor Pass                                       │
```
