### 1.2 Key Features

| Module | Features | Target Users |
|--------|----------|--------------|
| Visitor Pass Management | Create, issue, print visitor passes with QR codes | Reception Staff |
| QR Code Scanning | Entry/exit verification and tracking | Security Guards |
| Entry/Exit Tracking | Record visit times, duration, gate information | Guards, Admins |
| Field Inspection | Scan worker QR codes for safety audits | Auditors |
| NCR Management | Track and close non-conformance reports | Safety Managers |
| Security Dashboard | Real-time monitoring and analytics | Administrators |

### 1.4 Pass Status Flow

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│  Issued  │────>│  Active  │────>│   Used   │
│          │     │(On-site) │     │(Exited)  │
└──────────┘     └──────────┘     └──────────┘
     │                │
     │                │           ┌──────────┐
     │                └──────────>│ Expired  │
     │                            └──────────┘
     │
     v
┌──────────┐
│Cancelled │
└──────────┘
```

| Status | Description |
|--------|-------------|
| Issued | Pass created, visitor not yet entered |
| Active | Visitor currently on premises |
| Used | Visitor has exited (single-day pass) |
| Expired | Pass validity period ended |
| Cancelled | Pass manually cancelled |

## 10. Troubleshooting & FAQ

### 10.1 Visitor Pass Issues

| Problem | Cause | Solution |
|---------|-------|----------|
| QR code won't scan | Poor lighting or quality | Ensure good lighting, reprint if needed |
| "Pass not found" error | Invalid pass number | Verify pass exists in system |
| "Pass expired" error | Validity ended | Contact reception for new pass |
| "Pass not yet valid" | Early arrival | Wait until valid time |
| Duplicate scan blocked | 5-min cooldown active | Wait for cooldown period |

### 10.2 Inspection Issues

| Problem | Cause | Solution |
|---------|-------|----------|
| No template found | Template not configured | Contact admin to set up template |
| NCR not generated | Score >= 80% or no failures | NCR only created when score < 80% AND has failures |
| Cannot view history | No prior inspections | Worker has no previous records |

### 10.3 System Issues

| Problem | Cause | Solution |
|---------|-------|----------|
| Cannot login | Wrong credentials | Verify email/password or reset password |
| Page loading slow | Network issues | Check internet connection, refresh page |
| Notifications not received | Email not configured | Verify email settings in employee record |

## Appendix

### Appendix A: Pass Number Format

```
VP-YYYYMMDD-####

VP        = Prefix (Visitor Pass)
YYYYMMDD  = Date (e.g., 20251127)
####      = Daily sequence (0001-9999)

Example: VP-20251127-0001
```

### Appendix B: QR Code Data Structure

```json
{
    "type": "VISITOR_PASS",
    "pass_number": "VP-20251127-0001",
    "name": "VP-20251127-0001",
    "visitor_name": "Rajesh Kumar",
    "visitor_from": "ABC Technologies Pvt Ltd",
    "to_meet": "Mr. Sharma",
    "department": "Engineering",
    "visitor_type": "Visitor",
    "valid_from": "2025-11-27 09:00:00",
    "valid_until": "2025-11-28 09:00:00",
    "status": "Issued"
}
```

### Appendix C: Inspection Scoring

| Score Range | Result | NCR Severity |
|-------------|--------|--------------|
| >= 80% | Pass | None |
| < 80% (>=3 failures) | Fail | Critical |
| < 80% (<3 failures) | Fail | Major |

### Appendix D: Status Definitions

**Visitor Pass Status:**
| Status | Description |
|--------|-------------|
| Issued | Pass created, visitor not entered |
| Active | Visitor currently on premises |
| Used | Visitor has exited (single-day pass) |
| Expired | Validity period ended |
| Cancelled | Manually cancelled by admin |

**NCR Status:**
| Status | Description |
