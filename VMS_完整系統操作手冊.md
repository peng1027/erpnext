### 1.2 功能模組說明

| 模組 | 功能 | 適用角色 |
|------|------|---------|
| 訪客通行證管理 | 建立、核發、列印訪客通行證 | 接待人員 |
| QR Code 掃描 | 入場/出場掃描驗證 | 警衛人員 |
| 進出記錄追蹤 | 記錄訪客進出時間、停留時間 | 警衛、管理員 |
| 現場稽核 | 掃描工人 QR Code 執行安全稽核 | 稽核人員 |
| NCR 管理 | 不符合報告追蹤與結案 | 安全管理員 |
| 安全儀表板 | 即時監控、統計分析 | 管理員 |

## 三、訪客通行證管理

### 3.1 建立新訪客通行證

**路徑：** 首頁 > Visitor Pass > + Add Visitor Pass

**步驟：**
1. 點選「+ Add Visitor Pass」
2. 填寫訪客基本資訊
3. 填寫拜訪資訊
4. 設定有效期間
5. 設定通知選項
6. 點選「Save」儲存

## 十、常見問題

### 10.1 訪客通行證相關

| 問題 | 解決方式 |
|------|---------|
| QR Code 無法掃描 | 確保光線充足，QR Code 清晰，或手動輸入通行證號碼 |
| 通行證已過期 | 聯繫接待處重新核發 |
| 通行證尚未生效 | 等待生效時間或聯繫接待處調整 |
| 重複掃描被阻擋 | 等待 5 分鐘冷卻時間 |

### 10.2 稽核相關

| 問題 | 解決方式 |
|------|---------|
| 找不到稽核模板 | 聯繫管理員確認模板是否啟用 |
| 稽核結果未顯示 NCR | NCR 僅在分數低於 80% 且有不合格項目時產生 |
| 無法查看工人稽核歷史 | 確認工人有使用過本系統的通行證 |

### 10.3 系統相關

| 問題 | 解決方式 |
|------|---------|
| 無法登入 | 確認帳號密碼正確，或聯繫管理員重設密碼 |
| 頁面載入緩慢 | 檢查網路連線，或嘗試重新整理頁面 |
| 通知未收到 | 確認 Email 設定正確，檢查垃圾郵件夾 |
