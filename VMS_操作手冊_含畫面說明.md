### 3.5 欄位說明表

| 欄位名稱 | 必填 | 說明 |
|----------|------|------|
| Pass Number | 自動 | 系統自動產生，格式：VP-YYYYMMDD-####  |
| Visitor Name | ✅ | 訪客姓名 |
| Mobile Number | - | 訪客手機號碼 |
| Visitor From | - | 訪客所屬公司/單位 |
| Visitor Type | ✅ | 訪客類型：Visitor/Contractor/VIP/Interview |
| ID Type | - | 證件類型：ID Card/Passport/Driver License |
| ID Number | - | 證件號碼 |
| Visitor Photo | - | 訪客照片（用於身份核對） |
| To Meet | ✅ | 拜訪對象（員工姓名） |
| Department | - | 拜訪部門 |
| Purpose | - | 拜訪目的 |
| Meeting Location | - | 會面地點 |
| Valid From | ✅ | 通行證生效時間 |
| Validity Days | ✅ | 有效天數（1-365天） |
| Valid Until | 自動 | 系統自動計算到期時間 |

## 8. 常見問題處理

### 8.1 問題排查表

| 問題 | 可能原因 | 解決方式 |
|------|----------|----------|
| QR Code 無法掃描 | 列印品質不佳 | 重新列印，確保清晰 |
| 顯示「通行證不存在」 | 通行證號碼錯誤 | 確認號碼正確或重新查詢 |
| 無法收到通知信 | Email 未設定 | 確認員工資料有填寫 Email |
| 掃描被阻擋 | 重複掃描保護 | 等待 5 分鐘後重試 |
| 狀態未更新 | 網路問題 | 檢查網路連線後重試 |

### 8.2 狀態說明

| 狀態 | 圖示 | 說明 |
|------|------|------|
| Issued | ⚪ | 已發行，尚未入場 |
| Active | 🟢 | 已入場，目前在廠區內 |
| Used | 🔵 | 已使用完畢（單日通行證） |
| Expired | 🟡 | 已過期 |
| Cancelled | 🔴 | 已取消 |

### 8.3 聯絡資訊

如遇系統問題，請聯繫：
- 系統管理員
- IT 服務台
